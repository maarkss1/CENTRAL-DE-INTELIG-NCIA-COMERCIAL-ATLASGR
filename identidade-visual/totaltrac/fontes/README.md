# Fontes Total Trac

## Fivo Sans

O manual define Fivo Sans como a família oficial e informa que a licença é gratuita para uso pessoal e comercial. Os binários não foram extraídos do PDF nem redistribuídos neste pack; instale-os a partir da publicação indicada pela própria marca e preserve o arquivo de licença fornecido pelo autor.

Fonte indicada pelo manual: <https://www.behance.net/gallery/53653425/Fivo-Sans-Typeface-Free-Font-Family>

Pesos necessários: Regular, Medium, Bold, Heavy e Black.

Uso recomendado:

- Heavy para títulos grandes.
- Medium para subtítulos.
- Regular para textos longos e interfaces web.

O CSS do pack usa a pilha `"Fivo Sans", Arial, sans-serif`; assim, há fallback legível enquanto a fonte oficial ainda não estiver instalada ou hospedada no projeto.
