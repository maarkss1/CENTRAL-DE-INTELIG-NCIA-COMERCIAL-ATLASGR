# Script Maintenance & Patch Repository

Esta pasta organiza os scripts de manutenção, diagnósticos e patches de ambiente que foram aplicados durante a fase de consolidação do projeto.

## Scripts Disponíveis
- `generate-diagnosis.cjs`: Diagnóstico de conectividade com banco de dados e rotas.
- `patch_env.cjs` / `patch_coldcall.cjs`: Utilitários de patch temporários.
- `seed_users.ts`: Povoamento inicial de executivos e leads de teste.
